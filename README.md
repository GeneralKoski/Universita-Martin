# Universita

Personal study material from my BSc and MSc in Computer Science at the
University of Parma, kept in one place so it stays searchable and backed up.

This is not a software project. It is notes, exercises, exam preparation and
assignments, organised into `Triennale/` (bachelor) and `Magistrale/` (master),
one folder per course. The code inside is coursework: small exercises and
university assignments, not maintained libraries.

Some folders also contain reference material gathered while studying, such as
course handouts and published papers. That material belongs to its respective
authors and is included here only for personal study.

My actual projects are in the other repositories on this account.
