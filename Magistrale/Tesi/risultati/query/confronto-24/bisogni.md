# I bisogni delle 24 query del confronto

Per ogni query, **prima di vedere un solo risultato**, scrivi in una o due frasi
cosa sta cercando chi la digita nel documentale di un comune: quali atti gli
servono e, se c'è un caso dubbio evidente, quali no. Regole nella parte 2 di
`../../../istruzioni-annotazione.md`.

Esempio, per una query che qui non c'è (`manutenzione del verde`): *atti che
affidano, pagano o regolano la cura di parchi, giardini e alberature comunali;
non lo sono gli atti che nominano un parco solo come luogo di un evento.*

- Scrivi dopo `Bisogno:`, anche su più righe. Non toccare le righe `##`.
- Le query con un refuso (`manutenzone strade`) cercano la stessa cosa della
  query giusta: puoi scrivere `come «manutenzione strade»` o ripeterla.
- Le query con un numero (`determina 1223`) cercano quell'atto: scrivi cosa
  conta come quell'atto (per esempio, se va bene lo stesso numero in un altro
  comune).
- Quando hai finito, dimmelo: il file si committa **prima** di preparare le
  pagine di annotazione, e lo strumento si rifiuta di prepararle finché il file
  non è completo e committato.
